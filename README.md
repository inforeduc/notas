# Evaluación docente de Zazarabicoa

Aplicación web para el docente: datos personales, años y asignaturas, plan de evaluación,
notas por lapso (1, 2 y 3), importación de secciones desde Excel y exportación a PDF y Excel.

## Publicar con GitHub Pages
1. Sube estos archivos a un repositorio de GitHub (el archivo principal es `index.html`).
2. En el repositorio entra a **Settings > Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, rama **main**, carpeta **/ (root)**, y pulsa **Save**.
4. Espera uno o dos minutos. La página queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

## Dónde se guardan los datos
Los datos se guardan en el navegador de quien usa la página (localStorage), no en GitHub.
Cada docente ve solo sus propios datos, y nada de lo que se escribe llega al repositorio.
Usa **Exportar > Copia de seguridad** para guardar un archivo .json de respaldo.
